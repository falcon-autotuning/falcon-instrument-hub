# Measurement script examples

The executable Lua examples, their instrument adapters, and their Teal sources
have moved to the instrument-controller repository's
[`tests/instrument-control`](../../../instrument-controller/tests/instrument-control/README.md).
That repository owns the mock ISAs, plugins, and the `measure_set_get` integration
test used to exercise the scripts through ISS.

The instrument ISA template examples in `teal-instrument-libs-examples/` remain
here.
